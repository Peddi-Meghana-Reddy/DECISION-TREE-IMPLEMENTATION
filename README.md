## Description
This task focuses on implementing and visualizing a Decision Tree model using the Scikit-learn library in Python. A Decision Tree is a supervised machine learning algorithm used for classification and prediction tasks. The Iris dataset is used to train and test the model. The dataset is divided into training and testing sets, and the Decision Tree Classifier is trained using the training data. The model then predicts outcomes for the testing data, and the accuracy of the model is calculated to evaluate performance.

This project helps in understanding:
- Data preprocessing
- Model training and prediction
- Accuracy evaluation
- Decision Tree visualization
